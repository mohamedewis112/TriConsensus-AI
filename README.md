# TriConsensus AI

Fail-safe multi-agent crypto paper-trading research system.

> **Current scope:** paper trading / dry-run only. Live trading is intentionally disabled.

Architecture: Bybit market data -> deterministic feature/ML evidence -> 3-agent full consensus -> deterministic risk engine -> simulated execution -> immutable decision/trade audit trail -> analytics dashboard.

Development happens on feature branches. `main` is kept minimal until a tested V1 is ready.
