# CHRONOS V8.2 — Hybrid Artificial Market Civilization

V8.2 connects the calibrated V8.1 transition ensemble to the V8.0 parallel-futures
engine.

## Decision hierarchy

1. Build learned Digital-Mind weights from realised next order flow.
2. Evaluate V8.1 calibration/sample/drift gate.
3. If the learning gate passes, parameterize the multiverse from learned return,
   order-flow and liquidity distributions.
4. If the gate fails for any reason, fall back to the transparent V8.0 simulator.
5. A fallback world can produce research diagnostics but cannot produce a WATCH edge.
6. Both paths retain zero paper/live authority.

## Learned multiverse

The model forecast is not repeated blindly through the horizon. Its mean effect decays,
while ensemble uncertainty, conformal uncertainty, flow uncertainty, liquidity
uncertainty and heavy-tail shocks expand the distribution of future paths.

## Trust passport

Every civilization forecast includes:
- sample count,
- calibration status,
- untouched evaluation coverage,
- drift status,
- ensemble disagreement,
- fallback reason,
- explicit paper/live authority = false.

This is designed so the system can say "I do not trust my learned future right now"
and automatically revert to an inspectable model.
