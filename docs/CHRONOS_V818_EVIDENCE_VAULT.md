# CHRONOS V8.18 — Multi-Window Evidence Vault

V8.18 prevents one favorable live window from becoming a false conclusion.

It pools only non-overlapping horizon evidence across independent fresh-forward
windows and requires repeated performance above each window's empirical base rate.

Qualification requires multiple windows, balanced pooled outcomes, enough independent
samples, positive probability skill in repeated windows, a significant pooled
directional edge, and stable source/horizon/model definitions.

The vault is research-only. Even a qualified vault does not grant paper or live
execution authority.
