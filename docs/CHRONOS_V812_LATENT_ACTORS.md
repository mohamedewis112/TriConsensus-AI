# CHRONOS V8.12 — Latent Actor Archetypes

V8.12 upgrades unexplained-flow detection into recurring behavioral archetypes.

It clusters residual flow events using market context such as return, basis, spread,
depth asymmetry, funding, open-interest change and time-of-day. Each stable cluster
receives a deterministic LATENT-ACTOR fingerprint.

The system deliberately does not identify a real person, institution or wallet owner.
It labels only recurring market behavior and measures whether that residual behavior
tends to lead subsequent order flow.

Archetypes are research-only and carry no execution authority.
