# CHRONOS V8.9 — Public Live Shadow

V8.9 is a credential-free real-market experiment.

It samples public Bybit and Binance futures order books for BTCUSDT and ETHUSDT,
adds Bybit funding/open-interest and real 1m/5m price context, creates real MarketState
transitions, then runs the same chronological calibration and learned multiverse.

The capture is intentionally short and highly correlated. Results are a connectivity
and calibration smoke, not profitability evidence. No execution authority exists.
